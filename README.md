# 퓨처앤드림아카데미 1기 AI 클래스 포트폴리오

HTML·CSS·바닐라 JavaScript로 만든 공개용 정적 사이트입니다.

## 포함 자료
- PDF 첫 페이지 미리보기 12개
- 팀원별 포스터 20개
- 팀 공동 카드뉴스 20장, 팀별 순서대로 배치
- 프로모션웹 19개: 화면 캡처 18개, 접근 제한 안내 1개

기획안 이미지를 클릭하면 PDF가, 웹 캡처를 클릭하면 원래 사이트가 새 창에서 열립니다.

## 공개 범위
설문 응답 Excel, 원본 ZIP, 원문 CSV 내보내기, Word·Markdown 원본, 개발용 백업과 로컬 서버 파일은 포함하지 않았습니다. 전체 수집 자료는 로컬 원본 폴더에 보존됩니다. 각 자료의 저작권은 작성자와 소속 팀에 있습니다.

## GitHub Pages
main 브랜치의 루트(/)를 게시 소스로 사용합니다. 빌드나 외부 라이브러리는 필요하지 않습니다.
